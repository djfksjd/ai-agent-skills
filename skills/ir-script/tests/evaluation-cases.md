# Agent acceptance scenarios — not executed runtime tests

These prompts define manual/agent evaluation expectations. They are not counted among the 24 Python tests.

| Prompt situation | Expected behavior |
|---|---|
| Create a seed IR and script from supplied files | Read files, establish audience/time, research, generate synchronized artifacts |
| Revise only slide title style | Preserve facts and structure; audit titles without unnecessary BM reinvention |
| Video cannot be accessed | Record gap; no invented transcript or timestamps; use inspected primary references |
| Competitor advertises matching plus writing | Do not classify it as writing-only to manufacture a moat |
| Source deck and script have different appendices | Flag version mismatch and build an explicit mapping |
| User says personal AI plan through CLI | Preserve that model and check official integration rules; no silent BYOK replacement |
| Early-stage company has no revenue | Use truthful validation plan; no invented growth graph or customers |
| Public-company earnings call | Date/reporting basis, drivers, outlook and Q&A; no default seed fundraising ask |
| Upload reusable skill to public GitHub | Exclude source company files, customer details, credentials and copyrighted media |
| Ask for stock purchase recommendation | Outside this skill's presentation scope |
